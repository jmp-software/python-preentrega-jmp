# 🐍 Preentrega para curso de iniciación a la programación con Python de Talento Tech - Comisión 26209

## 💻 Sistemas testeados

- 🪟 Windows 10
- 🐧 Linux (Arch)

## 📥 Descargar el proyecto

Clonar el repositorio:
```
    git clone https://github.com/jmp-software/python-preentrega-jmp.git
```

Ingresar al directorio del proyecto:
```
    cd python-preentrega-jmp
```

## ▶️ Cómo ejecutar

### 🪟 Windows

Ejecutar el archivo:
```
    ejecutar.bat
```

### 🐧 Linux

Si es necesario, primero darle permisos de ejecución:
```
    chmod +x ejecutar
```
Luego ejecutar:
```
    ./ejecutar
```

## 📊 Flujo de ejecución

```
        🐍 Python
           │
           ▼
      📂 Proyecto
        /      \
       ▼        ▼
   🪟 Windows  🐧 Linux
       │          │
       ▼          ▼
 ejecutar.bat   ./ejecutar
```
